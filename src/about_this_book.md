# 이 책에 대하여

이 책은 Apple Macintosh 컴퓨터를 사용하여 제작되었습니다.

책의 샘플 코드를 편집하고 테스트하는 데에는 Digitool 의 Macintosh Common Lisp (MCL) 을 사용했습니다. 또한, Bill St. Clair 이 개발한 HTML-Editor.lisp 를 확장하여 MCL 에디터가 이 책의 구성에 사용된 HTML 마크업 언어를 처리할 수 있도록 했습니다. 이를 통해 책의 소스 파일 내에서 직접 Lisp 코드를 편집하고 테스트할 수 있었으며, 샘플 코드를 잘라 붙이는 과정에서 발생할 수 있는 오류들을 사전에 방지할 수 있었습니다.

이 책을 웹 브라우저로 확인하기 위해 다양한 웹 브라우저를 사용했습니다.

철자 검사는 Robert Gottshall 과 Rick Zaccone 가 개발한 Excalibur 를 활용했으며, 사전을 대체하고 동의어 검색을 위해서는 Wordstar International 의 The American Heritage Dictionary Deluxe Edition (컴퓨터 버전) 을 사용했습니다.

이 책의 제작에 사용된 모든 소프트웨어와 하드웨어는 전액 저자의 개인 비용으로 구매되었습니다. 저는 사용하는 공유 소프트웨어 (shareware) 제품들을 구매함으로써 이를 지원하고 있습니다.
